# Learn Africa: Professional Computing course setup guide

This guide explains how to create the Professional Computing course and add its 11 topics using the existing Learn Africa instructor curriculum editor.

The learning sequence for **each topic** must be:

1. **Custom Page** — reading material, illustrations, explanations, examples and key terms only.
2. **Video Lesson** — a separate curriculum item created by the instructor using the existing Video Lesson option.
3. **Text Lesson** — a separate item containing the practical activity or task instructions.
4. **Quiz Lesson** — a separate assessment item, where a lesson assessment is required.

Do not put a YouTube link, video player, video search link or practical activity inside the Professional Computing custom reading page. The custom page is for reading only. The video, activity and assessment must be separate course items.

## 1. Create the course

1. Sign in to Learn Africa using your instructor account.
2. Open **Instructor Dashboard**.
3. Select **Create Course**.
4. Enter the course details below.

| Field | Suggested value |
|---|---|
| Course title | Professional Computing |
| Description | A Ghana-focused introduction to professional ethics, responsible technology use, cybercrime, privacy, intellectual property, software development, technology and society, organisational ethics and Ghana’s Data Protection Act, 2012 (Act 843). |
| Category | Information Technology, or the closest available category |
| Difficulty | Intermediate |
| Course code | PC-101 |
| Tags | Ethics, Professional Computing, Information Technology, Cybersecurity, Privacy, Copyright, Ghana |
| Weeks required | 6 (adjust to your teaching schedule) |
| Initial rating | 0 for a new course |
| Number of reviews | 0 for a new course |

Add the course learning outcomes from the course pack. Set the price and certificate options according to your course plan. The course hours are calculated from the lesson durations you enter in the curriculum.

## 2. Build the curriculum

Open the **Curriculum** step. Create the course section or sections you need. For every topic, add the four items in the order shown below.

### Item A: Custom Page (reading)

1. Select **Custom Page**.
2. Enter the topic title.
3. Find the custom page component selector, labelled **Select component** in the custom lesson editor.
4. Choose the matching **Professional Computing** component from the table below.
5. Set the duration and save.

The custom page provides the topic reading, learning outcomes, Ghana-focused example, key terms and lesson illustration. It does not contain the video lesson or practical activity.

### Item B: Video Lesson

1. Select **Video Lesson** directly after the custom page.
2. Give it a clear title, for example, **Video: An Overview of Ethics**.
3. Paste the selected video URL into the video URL field.
4. Check the preview and save the item.

Choose a video from a credible university, educational institution, regulator or professional organisation. Check the presenter, topic accuracy, date, relevance and suitability for your learners. The course pack provides suggested YouTube search phrases, not verified individual video recommendations. Search for a suitable video yourself and add its actual URL to the separate Video Lesson item.

For the Act 843 topic, prioritise Ghanaian sources and explanations of Ghana's law. Do not substitute a video that only discusses US or UK privacy legislation.

### Item C: Text Lesson (practical activity)

The current curriculum editor provides **Text Lesson** as a separate item type. Use it for the practical activity that follows the video.

1. Select **Text Lesson** after the Video Lesson.
2. Give it a clear title, for example, **Practical Activity: An Overview of Ethics**.
3. Put the practical task instructions in the text lesson content.
4. Explain what the learner should produce and how to submit it, using the submission method available for your course.
5. Save the item.

Use the practical activity prompt for the matching topic from the expanded course pack. Do not put the activity inside the custom reading page.

### Item D: Quiz Lesson (assessment)

1. Select **Quiz Lesson** after the practical activity.
2. Give the quiz a clear title, such as **Lesson 1 Assessment: An Overview of Ethics**.
3. Add the questions and correct answers in the instructor quiz editor.
4. Configure the pass score, timer, included attempts and any extra-attempt fee according to your course policy.
5. Save and preview the assessment.

Keep answer keys out of all student-visible reading and activity content. The existing Learn Africa quiz system should continue to manage assessment attempts, retry rules and scoring.

### Example: how Lesson 1 should appear in the curriculum

1. **An Overview of Ethics** — Custom Page
2. **Video: An Overview of Ethics** — Video Lesson
3. **Practical Activity: An Overview of Ethics** — Text Lesson
4. **Lesson 1 Assessment: An Overview of Ethics** — Quiz Lesson

Repeat this sequence for the remaining topics. Keep the final examination separate from the 11 lesson assessments.

## 4. Final examination

After Lesson 11, add a separate final examination using the existing **Quiz Lesson** item and final-exam settings. Mark it as the final examination through the existing instructor controls. Configure the pass mark, timer and attempt policy carefully.

The supplied expanded course pack does not contain a complete 50-question bank for every lesson or a complete 150-question final examination bank. Do not describe the supplied questions as complete banks unless the additional questions have been written, reviewed and added.

## 5. Preview and quality checks

Before publishing:

1. Open the instructor course preview.
2. Confirm each custom page contains reading material and illustrations only.
3. Confirm no video player, YouTube search link or practical activity appears inside the custom page.
4. Confirm the separate Video Lesson follows the custom page and its video plays.
5. Confirm the Text Lesson follows the video and contains the practical activity.
6. Confirm the Quiz Lesson follows the activity.
7. Check all 11 topics and the final examination.
8. Review text alignment, spacing, images and navigation on both desktop and mobile.
9. Test assessments with a test learner account.
10. Confirm course completion and certificate settings before publishing.

Do not change existing quiz attempt, retry-fee, final-examination reset or certificate settings as part of adding these lessons. Test those existing behaviours rather than replacing them.

## 6. Official Ghana data protection references

- Ghana Data Protection Act, 2012 (Act 843): https://ghalii.org/akn/gh/act/2012/843/eng@2012-05-18
- Data Protection Commission, Individuals: https://dpc.gov.gh/for-individuals/
- Data Protection Commission, Organisations: https://dpc.gov.gh/for-organisations/
- Data Protection Commission, Compliance: https://dpc.gov.gh/compliance/

The Act 843 lesson is an educational overview, not legal advice. Consult the legislation and current Data Protection Commission guidance for legal and compliance decisions.
