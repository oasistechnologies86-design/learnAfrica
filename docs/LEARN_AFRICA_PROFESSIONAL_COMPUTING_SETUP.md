# Learn Africa: Professional Computing course setup guide

This guide uses the existing Learn Africa instructor course creator and the Professional Computing custom lesson pages.

## Before creating the course
1. Sign in with your instructor account.
2. Open **Instructor Dashboard** and choose **Create Course**.
3. Prepare a course thumbnail, a short course description and the course learning outcomes.
4. Use the course title **Professional Computing**. Choose the closest available category and difficulty level that matches the intended learners.
5. Set the price and certificate option according to your course plan.

## Course basics
- **Title:** Professional Computing
- **Description:** A Ghana-focused introduction to professional ethics, responsible technology use, cybercrime, privacy, intellectual property, software development, technology and society, organisational ethics and Ghana’s Data Protection Act, 2012 (Act 843).
- Add the course outcomes from the course pack.
- Add a suitable thumbnail and tags such as Ethics, Information Technology, Cybersecurity, Privacy, Copyright and Ghana.

## Build the curriculum
In the Curriculum tab, create sections in the order below. Add one lesson item per topic. For each lesson:
1. Add a lesson and set its type to **Custom Page**.
2. Open **Select component**.
3. Choose the matching Professional Computing page key from the list.
4. Save the lesson item and set its duration.
5. Add a separate **Quiz** item after the custom lesson if you want the assessment to appear in the course navigation. Do not put answer keys in student-visible reading content.

## Add lesson videos
The lesson pages include YouTube search phrases from the course pack. These are search links, not pre-verified video recommendations.
1. Open the search link from the lesson page.
2. Choose a video from a credible university, educational institution, regulator or professional channel.
3. Check that the video teaches the correct topic and is current.
4. Copy its YouTube URL.
5. In the instructor curriculum editor, add a separate Video lesson after the custom reading page and paste the URL. This keeps the reading before the video in the learning sequence.
6. Preview the video and confirm it plays on desktop and mobile.

For Lesson 11, use Ghanaian or African sources that accurately explain Act 843. Do not substitute a video that only explains US or UK privacy law.

## Practical activities and assessments
The custom page includes the practical activity prompt. Add a separate assignment or discussion item if you want students to submit their work through Learn Africa. Add the lesson quiz as a separate Quiz item and configure its pass score, timer, attempts and any retry fee using the existing controls.

The expanded course pack contains answer keys immediately after questions. Do not paste those answer keys into student-visible lesson text. The supplied lesson question sets and final exam are not complete 50-question and 150-question banks respectively, so do not label them as complete banks without adding and checking the remaining questions.

## Final examination
Add a separate final examination item after Lesson 11 using the existing quiz type and final-exam settings. Configure its pass mark, timer and attempt policy. Test the pass, fail, retry and certificate behaviour using a test learner account before publishing.

## Preview and publish
1. Use the instructor **Preview** option to inspect every lesson.
2. Check the reading, visual layout, YouTube link, activity and quiz navigation.
3. Repeat on a phone-sized screen and a desktop screen.
4. Check that the lesson sequence is correct and that no lesson is missing.
5. Test a lesson quiz and the final exam with a test learner account.
6. Confirm the course completion and certificate rules before publishing.

## Official Ghana data protection references
- Ghana Data Protection Act, 2012 (Act 843): https://ghalii.org/akn/gh/act/2012/843/eng@2012-05-18
- Data Protection Commission, Individuals: https://dpc.gov.gh/for-individuals/
- Data Protection Commission, Organisations: https://dpc.gov.gh/for-organisations/
- Data Protection Commission, Compliance: https://dpc.gov.gh/compliance/

The Act 843 lesson is an educational overview, not legal advice. Check the legislation and current Data Protection Commission guidance for legal and compliance decisions.
